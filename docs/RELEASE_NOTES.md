Auris 0.1.13 — Ratings and saved feedback in Library (Android 8.0 or newer).

- Anime and manga titles opened from the Library now show their rating; missing ratings are fetched and stored instead of staying blank.
- The "Saved to Library" feedback now appears in the description area and stays when you return to a saved title.
- Adding a song to a playlist is one tap on the playlist; Create playlist also adds the song, and duplicates are reported honestly.
- Playing a created playlist now shows the mini-player and works through the full queue.
- The Library groups titles by type (Anime / Manga / Music) and shows created playlists alongside them.

The security, authentication, navigation, and playback changes from previous previews remain included. Older debug previews (`com.auris.app.debug`) are a separate installation; local data is not automatically transferred between packages.

This remains a preview. Provider availability varies by network; backend authorization and broader playback/device checks remain separate from the regression checks.
